# Projeto Alura Store Brasil

Este repositório contém o notebook desenvolvido no Google Colab para o desafio da **Alura Store Brasil**.

## 📖 Descrição
O projeto tem como objetivo  avaliar o desempenho das quatro lojas da AluraStoreBrasil, considerando fatores como faturamento, categorias de produtos, avaliações dos clientes, frete médio e distribuição geográfica das vendas. A partir dos gráficos e métricas gerados, buscou-se identificar pontos fortes e fracos de cada loja e recomendar qual delas deve ser vendida pelo Senhor João.

## 🚀 Tecnologias utilizadas
- Python
- Google Colab
- Bibliotecas: pandas, numpy, matplotlib, seaborn, etc.

## 📂 Estrutura do repositório
- `AluraStoreBrasil.ipynb` → Notebook principal com todo o código e análises.
- `README.md` → Este arquivo de documentação.

## ▶️ Como executar
1. Baixe o notebook ou abra diretamente no Google Colab.
2. Instale as dependências necessárias (se houver).
3. Execute célula por célula para reproduzir os resultados.
